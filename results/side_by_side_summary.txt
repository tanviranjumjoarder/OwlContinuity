IMPORTANT CAVEAT ABOUT THIS TEST
The demo text itself is very structured: it lists every rule and explicitly asks for "the domino effects, the math check and a student announcement draft". That gave the plain chat the same hints our agent's instructions give. This was intentional (it makes the test hard for us), but it also means this case cannot show the agent's main advantage, which is that a professor does NOT have to write such a careful prompt.

WHAT TO SAY IN THE PITCH (true to these results)
"We tested it against a plain owlONE chat with the same model and the same inputs. Both found the right plan, so the model is capable. Our agent got there in about 90 seconds instead of about 9 minutes, calculated every hour with code instead of in its head (the plain chat got one number wrong), and returned the same checkable packet every time, so a professor can trust and verify it in seconds."

SUGGESTED NEXT COMPARISONS (where the agent's rules should matter more; not yet run)
