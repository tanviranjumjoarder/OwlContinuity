The three agents

Instructor Desk (professor) runs the Domino Effect Agent: move one class, and it follows every deadline that depends on it, hands back a draft schedule, and writes the Canvas announcement with the new dates for the professor to post. Before an assignment goes out, it also flags unclear steps, instructions that contradict each other, and readings with no link. In owlONE it runs on gpt-6-luna with code tools on for the time math and internet search off.

Student Helper (student) answers the questions professors and TAs get before every deadline: how to submit, which file type, whether to attach code or add pictures, citation style, what to do when Canvas won't take a file. It uses only the course pack and the approved answer bank, and never guesses.

The real-syllabus agent runs the same workflow on a real FAU graduate syllabus, to check that it holds up outside a made-up course.

What the agent does, step by step

  1. Find what the closure hits. Any required class or deadline inside the closure must move.
  2. Try the allowed times. Only the professor's make-up slots, the backup lab time and the listed options. Earliest first, fewest changes.
  3. Recheck every linked deadline with code. Times are read in America/New_York and converted to UTC before subtracting, so the Nov 1 clock change adds an hour.
  4. Return a draft or ask. If every rule passes, it's a DRAFT for the professor. If no plan fits, it says NEEDS DECISION and names the rule that blocks it.

What this page leaves out

The owlONE agents read free text: syllabi, notices and emails in everyday words. This page has the DEMO-101 course built in, and the Student Helper matches questions with simple patterns instead of a language model. It shows the rules and the approval loop, not the language understanding.

Limits, stated plainly

This is a prototype tested with small test sets I wrote myself. There's no FAU approval, no Canvas integration, no automatic sync and no measured time savings. Every schedule is a draft that the professor reviews and publishes.
